# Tecinternet2

## Descrição

Projeto com foco em aplicações web e autenticação desenvolvido na linguagem PHP, explorando sessões, formulários e integração no backend.

## Tecnologias Utilizadas

- PHP

## Funcionalidades

- Sistema de login e autenticação
- Manipulação de sessões
- Processamento de formulários

## Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/vitoriasaldanha22/Tecinternet2.git
   ```
2. Coloque os arquivos em um servidor local (por exemplo, XAMPP, WAMP, MAMP) na pasta do servidor (htdocs/www).
3. Acesse via navegador para testar as funcionalidades.
